# Sparkle Brand Shop Shopify Theme

This repo is a native Shopify Online Store 2.0 theme scaffold built from the brand aesthetic and storefront structure of the Lovable storefront reference.

## Included theme files
- `layout/theme.liquid`
- `templates/index.json`
- `templates/product.json`
- `templates/cart.liquid`
- `templates/page.liquid`
- `templates/collection.json`
- `sections/*.liquid`
- `assets/style.css`
- `assets/script.js`
- `config/settings_schema.json`

## How to package for Shopify ZIP upload
1. Zip the theme directory contents directly.
2. Make sure the root of the zip contains the Shopify theme folders such as `layout`, `templates`, `sections`, `assets`, and `config`.
3. Upload the zip to Shopify Admin > Online Store > Themes > Add theme > Upload zip file.

## Notes
- This is a white-labeled, native Shopify theme scaffold ready for theme upload.
- Product, collection, and media data should be connected to real Shopify data after upload.
- If you want closer visual parity to the original Lovable design, refine the theme settings and upload the final storefront assets in Shopify admin.
